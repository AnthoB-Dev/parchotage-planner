# Parchotage Planner

Outil web statique (HTML/JS, déployé sur GitHub Pages) qui calcule la combinaison de parchemins la moins chère pour parchoter les statistiques d'un personnage de Dofus 3. Périmètre v1 : coût en kamas uniquement.

## Statut et périmètre

- Usage **strictement non commercial** : outil personnel, sans vente, monétisation ni publicité.
- Catalogue des parchemins : liste statique embarquée dans l'outil, fournie et validée par l'auteur. Aucun appel à une API externe au runtime ni au build.
- Prix kamas : saisis manuellement par l'utilisateur, mémorisés localement (localStorage).

## Méthode de développement

Outil co-développé avec un assistant IA piloté par l'auteur : l'auteur humain reste l'auteur principal, valide chaque décision et révise le travail produit.
